# S0.5 · 带着执行边界问题读 OpenAI

上游指定原文：[A practical guide to building agents](https://openai.com/business/guides-and-resources/a-practical-guide-to-building-ai-agents/)。阅读时不要跳到另一个“新工具发布”页面替代这份指南。

## 原文要点（短摘要）

指南以模型、工具、指令作为基础组成，讨论适合自主决策的任务、从单 Agent 逐渐扩展的编排方式，以及约束与人工介入。多 Agent 应用于具体分工需求，并不是默认起点。

## 本课程自己的应用：谁有权把一句话变成动作

资料助手得到 `read_file` 请求后，模型只是提出路径；运行时还要核对工具名、参数、路径范围与预算，再由函数真正读取。网页正文可以提供事实，却不能给模型新增写入权限。最后“回答已完成”必须和实际证据对齐。

假如把研究拆成三个角色，先说明单个循环的瓶颈：上下文混杂？任务可独立并行？还是需要不同工具权限？没有这个证据，新增角色只增加来源交接和结果冲突。先让单循环的目标、工具、状态和验收清楚，再决定是否值得拆分。

阅读后应能解释：本任务的模型选择什么？工具实际能改变什么？指令与程序校验各承担什么？哪类失败需要交回用户？这些问题对应后续工具、Harness 与安全章节的具体设计。
