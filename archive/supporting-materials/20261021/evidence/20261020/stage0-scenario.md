# Stage 0 阶段作品：资料研究何时值得使用 Agent

用户需要理解一套Agent学习路线的要求，并把结论追溯到官方原文。成功标准是问题得到逐项回答、引用来自实际读取的来源、冲突和缺口显式报告；模型写出一篇流畅文章不够。

对已经固定的两篇材料做摘要，用“读文件→摘要→格式检查”的workflow更容易控制。处理陌生子问题时，下一步会受新观察影响：检索空结果需要换查询，来源矛盾需要核对范围和日期，资料读不到需要换来源或承认无法核验。只有这些不确定决策足够重要，才值得引入模型选择动作的Agent循环。

模型负责提出下一步请求；运行时负责校验参数、权限和预算；工具读取外部信息；结果回写到上下文；独立验收判断结论是否被证据支持。长期记忆、多Agent和浏览器均是可选设计，不能凭组件数量证明任务需要Agent。

代价包括更多调用与延迟、错误累积、来源污染、过早终止和重复动作。先保留固定检索基线，再对比动态工具循环，用任务成功、来源支持、工具次数和延迟衡量是否值得。模型找不到证据时可以合法地缺证结束；系统必须允许它报告不足。

本课程选择研究助手作为贯穿任务，是为了观察这些控制点，而非宣称所有资料问答都需要Agent。Stage 1已经保存一个反例：模型没有读文件就编造来源与阶段；证据门能拦截这类完成声明，但不能自动保证引用或语义正确。
