# 原网页模块归档

网页展示模块已退出学习主线。请从根目录 [README](../../README.md) 进入编号课程，用 Jupyter / VS Code 打开 Notebook。

| 路径 | 原内容 |
| --- | --- |
| site/ | 前端页面、样式、脚本、依赖资源与构建产物。 |
| python/ | 网页目录生成、课程渲染、HTTP 服务及网页检查代码。 |
| start-learning.bat | 原网页启动器。 |
| outputs/ | 原网页任务、界面检查和服务日志；属于本地历史产物，不提交版本控制。 |

这里保留原始文件便于回看。旧启动器及服务仍使用重构前路径，未维护为新的可运行入口。
